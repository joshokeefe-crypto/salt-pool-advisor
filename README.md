# Salt Pool Advisor v5

Upload every file in this folder to the top level of the GitHub repository.

GitHub Pages:
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

Features:
- Chemistry guidance and dosing estimates
- History and trend analysis
- Live weather using saved coordinates
- Maintenance reminders
- Chemical inventory
- Test photo attachments
- Export/import backup
- Offline PWA support

Important limits:
- Reminders appear when the app is opened. They are not background push notifications.
- Photos are stored as attachments. The app does not automatically read Taylor test colors.
